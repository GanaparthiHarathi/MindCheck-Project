# MindCheck

MindCheck is a web-based depression assessment application that helps users evaluate their mental well-being through a questionnaire-based screening process.

## Features

* Questionnaire-based depression assessment
* Instant result generation
* Multiple severity levels
* Responsive user interface
* Educational mental health resources

## Technologies Used

* Python
* Flask
* HTML
* CSS
* Bootstrap
* JavaScript

## Live Demo

https://mindcheck-hqgk.onrender.com

## Disclaimer

This application is intended for educational and screening purposes only and is not a substitute for professional medical diagnosis or treatment.
